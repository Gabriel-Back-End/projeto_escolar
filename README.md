#Sistema de Gestão para Transporte Escolar
Descrição
Este projeto nasceu da observação direta de uma dor latente no setor de transporte escolar: a dificuldade de gestão financeira. Muitos condutores (os "tios e tias das vans") realizam o controle de pagamentos de forma manual ou descentralizada, o que gera erros, esquecimentos e falta de previsibilidade de caixa.

O sistema foi desenvolvido para ser uma solução centralizada e intuitiva, permitindo que o gestor tenha o controle total sobre o status de pagamento de cada aluno e a saúde financeira do seu serviço em poucos cliques.

🎯 Objetivos e Funcionalidades
Controle de Fluxo de Caixa: Monitoramento em tempo real de entradas e pendências.

Gestão de Alunos: Cadastro detalhado de passageiros vinculado aos responsáveis financeiros.

Status de Mensalidades: Identificação visual rápida de pagamentos efetuados, atrasados ou próximos do vencimento.

Otimização de Processos: Substituição de agendas físicas por um banco de dados confiável e acessível.

🛠️ Tecnologias Utilizadas
Back-end: [PHP ou Python] – Responsável pela lógica de negócios e processamento de dados.

Banco de Dados: SQL – Estrutura relacional para garantir a integridade dos dados financeiros.

Front-end: HTML, CSS e JavaScript – Interface focada na usabilidade e responsividade.

🚀 Impacto
A aplicação transforma um processo burocrático e passível de falhas em um fluxo de trabalho profissional, reduzindo a inadimplência e poupando tempo administrativo para o condutor focar no que é mais importante: a segurança dos alunos.
